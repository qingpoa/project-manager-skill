# 模块上下文

## 职责与入口

说明现行职责、边界、实际入口和来源路径。

## 关键流程与依赖

简述当前调用/数据关系、上游下游和接口来源。方案已被替代时更新原描述，旧流程的历史价值留在任务或明确标注的交付资料中。

## 配置与开发命令

从定义文件核对配置键、启动/检查命令及环境前提，不复制配置值。近期检查结果链接到 STATE 或对应 TASK/records，不在这里独立维护测试计数和多轮测试详情。

## 仍存边界

记录当前真实限制、Mock 边界和必要约定，引用出处；已解决的问题从本节移除。一次性的服务启动结果、库数据条数和环境快照留在原任务记录。

## 维护信息

填写已确认的维护者（未知则待确认）、实际核实时间/范围。只检查部分内容时说明范围；稳定内容可以保持，不因日期旧而机械删改。

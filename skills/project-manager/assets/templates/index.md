# 项目管理入口

## 项目概览

填写项目名称、用途与当前重点。完整目标见 [PROJECT.md](PROJECT.md)，当前核实状态见 [STATE.md](STATE.md)。

## 管理资料

| 资料 | 用途 |
| --- | --- |
| [PROJECT.md](PROJECT.md) | 目标、范围与约束 |
| [BACKLOG.md](BACKLOG.md) | 用户主动添加的需求及完成勾选 |
| [STATE.md](STATE.md) | 当前状态、阻塞与下一步 |

仅为实际存在的模块、工作计划、任务、接口资料添加链接；若已启用可选的 `.project/CONVENTIONS.md`（编码与架构规范），同样在此补充链接。

## 模块总览

用带一句职责注解的目录树展示模块根目录，并在下表链接各模块地图与上下文。

| 模块 | 代码根目录 | 目录地图 | 模块上下文 |
| --- | --- | --- | --- |

## 阅读路线

- 接手任务：当前状态 → CONVENTIONS（若存在） → 目标任务 → 来源想法/计划和接口 → 涉及模块 → 最近工作记录。
- 查找文件：模块总览 → 模块地图。
- 查看进度：当前状态 → 关联任务 → 实际结果及检查依据。
- 记录需求：用户直接编辑 BACKLOG，或明确要求智能体加入清单；每条仅显示需求与完成勾选。

## 维护约定

记录文档语言、路径规则、已确认维护者及采用的任务认领方式。管理资料中的代码路径相对于仓库根目录；导航链接相对于当前文档。任务状态以对应 TASK.md 为准。

INDEX 只做导航，不追加按日期排列的交付/测试流水。STATE 按当前事实替换更新，CONTEXT 保留稳定职责；历史过程在对应 TASK/records。

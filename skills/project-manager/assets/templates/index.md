# 项目管理入口

## 项目概览

填写项目名称、用途与当前重点。完整目标见 [PROJECT.md](PROJECT.md)，当前核实状态见 [STATE.md](STATE.md)。

## 管理资料

| 资料 | 用途 |
| --- | --- |
| [PROJECT.md](PROJECT.md) | 目标、范围与约束 |
| [BACKLOG.md](BACKLOG.md) | 随时追加需求、灵感，查看整理和采纳结果 |
| [STATE.md](STATE.md) | 当前状态、阻塞与下一步 |

仅为实际存在的模块、工作计划、任务和接口资料添加链接。

## 模块总览

用带一句职责注解的目录树展示模块根目录，并在下表链接各模块地图与上下文。

| 模块 | 代码根目录 | 目录地图 | 模块上下文 |
| --- | --- | --- | --- |

## 阅读路线

- 接手任务：当前状态 → 目标任务 → 来源想法/计划和接口 → 涉及模块 → 最近工作记录。
- 查找文件：模块总览 → 模块地图。
- 查看进度：当前状态 → 关联任务 → 实际结果及检查依据。
- 记录想法：BACKLOG 的“随手记录”，可以直接追加普通条目；规划时再整理。

## 维护约定

记录文档语言、路径规则、已确认维护者及采用的任务认领方式。管理资料中的代码路径相对于仓库根目录；导航链接相对于当前文档。任务状态以对应 TASK.md 为准。

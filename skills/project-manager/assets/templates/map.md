# 模块目录地图

## 覆盖与核实

- 模块：填写实际模块名称。
- 覆盖根目录：填写仓库相对路径。
- 核实时间与版本：填写实际时间及可获取的提交；有未提交改动则注明。
- 完整性：明确完整或部分，以及待扫描范围。
- 省略规则：列出依赖、缓存、产物、敏感文件等实际排除项。

## 目录树

在 text 代码块中写实际目录树。每个纳入范围的文件后以 `#` 写一句从内容核实的职责。目录也可加简短说明。无法确认的作用标为待确认。

## 子地图

大型模块在这里链接负责具体子目录的 MAP.md，并明确覆盖边界。没有子地图则省略本节。

## 待确认

记录未读文件、未知资源用途或尚未纳入范围的目录；无则写“无”。
